## How I approach development

1. Understand the operational problem and identify a measurable outcome.
2. Choose the simplest maintainable solution: scripts, APIs, low-code, or an application.
3. Use AI where it accelerates research, implementation, and debugging.
4. Verify generated code, error handling, security, and regression risks.
5. Document what works, what is still experimental, and what remains to be tested.
