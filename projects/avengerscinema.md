# AvengersCinema — Android TV & Android Application

**Type:** Independent application-development project  
**Primary device:** NVIDIA Shield TV Pro (Android TV / ARM64)  
**Source:** Private repository

## Project overview
A native Android multimedia interface designed for remote-control navigation on Android TV, with touch interaction for Android smartphones.

## Engineering areas
- Kotlin and Android UI, navigation and focus management for TV remotes.
- Touch navigation and selection behaviour on smartphones.
- Metadata/API integration and catalogue browsing.
- Playback integration and application state management.
- Build and release workflows, Android packaging and update compatibility.
- Targeted troubleshooting using ADB and developer tooling.

## What it demonstrates
Cross-device UI design, native app engineering, integration work, performance debugging, release discipline, and maintenance of an evolving application.
